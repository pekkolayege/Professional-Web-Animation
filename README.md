## 📌 Proje Hakkında

**Professional Web Animation**, HTML5, CSS3 ve Vanilla JavaScript kullanılarak geliştirilen modern web arayüzü çalışmalarını bir araya getirir.

Repo; görsel açıdan güçlü sayfa tasarımlarını, akıcı animasyonları, responsive düzenleri ve kullanıcı etkileşimlerini pratik bir frontend geliştirme yaklaşımıyla ele alır. Her çalışma, gerçek dünyadaki web projelerinde kullanılabilecek temiz, anlaşılır ve geliştirilebilir arayüz fikirleri sunmayı amaçlar.

## ✨ Öne Çıkan Konular

- Modern ve dikkat çekici web arayüzleri
- CSS transition, transform ve keyframe animasyonları
- Responsive ve mobil öncelikli tasarım yaklaşımı
- Vanilla JavaScript ile etkileşimli bileşenler
- DOM manipülasyonu ve event yönetimi
- Semantik HTML ve okunabilir kod yapısı
- Renk, tipografi ve mikro etkileşim odaklı kullanıcı deneyimi

## 🧰 Kullanılan Teknolojiler

| Teknoloji | Kullanım amacı |
| --- | --- |
| **HTML5** | Semantik sayfa yapısı ve erişilebilir içerik |
| **CSS3** | Görsel tasarım, responsive düzen ve animasyonlar |
| **JavaScript** | Etkileşim, dinamik davranış ve DOM yönetimi |

## 🚀 Başlangıç

Projeyi yerel ortamınızda çalıştırmak için:

```bash
git clone https://github.com/pekkolayege/Professional-Web-Animation.git
cd Professional-Web-Animation
```

Ardından repo içindeki ilgili proje klasörünü açın ve HTML giriş dosyasını tarayıcıda çalıştırın. Statik yapısı sayesinde ek bir build aracı veya paket kurulumu gerektirmeden incelenebilir.

> Daha iyi bir geliştirme deneyimi için Visual Studio Code üzerindeki **Live Server** gibi bir yerel sunucu eklentisi kullanabilirsiniz.

## 🗂️ Proje Yapısı

Her çalışma, kendi arayüz ve animasyon yaklaşımını içeren bağımsız bir frontend örneği olarak değerlendirilebilir. Projeleri incelerken aşağıdaki katmanlara dikkat edebilirsiniz:

- **HTML:** Sayfa iskeleti ve içerik hiyerarşisi
- **CSS:** Layout, responsive davranış ve animasyon detayları
- **JavaScript:** Etkileşimler, kullanıcı olayları ve dinamik güncellemeler

## 🎯 Öğrenme ve Geliştirme Hedefleri

Bu repo aşağıdaki frontend yetkinliklerini geliştirmek ve sergilemek için oluşturulmuştur:

- Tasarımdan uygulanabilir arayüze geçiş
- CSS animasyonlarını performanslı ve kontrollü kullanma
- Farklı ekran boyutlarında tutarlı deneyim oluşturma
- Kullanıcı etkileşimlerini sade JavaScript ile yönetme
- Yeniden kullanılabilir ve sürdürülebilir frontend kodu yazma

## 🤝 Katkıda Bulunma

Katkı sağlamak isterseniz:

2. Yeni bir branch oluşturun.
